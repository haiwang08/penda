# Penda TSF · Windows 中日英三语输入法

Let's typing！

0.2 已改为原生 C++ TSF 输入法。Windows 加载 x64 / x86 的 `Penda.Tsf.dll`，通过 TSF 编辑会话处理组合文字与提交，不再使用全局键盘钩子或模拟按键。独立的 .NET 设置程序只负责词库、宽度和预览，关闭设置程序也可以输入。

项目目录：`E:\projects\penda`。发布目录：`artifacts\tsf-package`。旧版 `artifacts\portable` 是 0.1 桌面原型，不属于当前 TSF 发布包，请不要同时运行。

## 安装与启用

当前提供可注册发布包与 Inno Setup 安装脚本；本机未安装 Inno Setup，尚未生成最终安装 EXE。

1. 先退出旧版 Penda 托盘程序，避免旧版钩子影响新版测试。
2. 将 `artifacts\tsf-package` 整个目录放在固定位置。正式分发建议用安装包装入 Program Files。
3. 在该目录以管理员身份打开 PowerShell，执行：

```powershell
.\register-tsf.ps1
```

4. 注销 Windows 并重新登录。在系统输入法列表选择 **Penda 中日英**。配置文件注册在简体中文（中国）`zh-CN / 0x0804` 下；若系统尚未安装此语言，先在“时间和语言 → 语言和区域”添加中文（简体，中国），再查看该语言的键盘列表。
5. 在支持 TSF 的桌面应用试用：`nihao` + 空格 → 你好；`nihongo` + 空格 → 日本語；`hello` + Enter → hello。

注册需要管理员权限。不要在注册后移动 DLL 所在目录。两种架构必须用对应位数的 regsvr32，脚本已自动处理。

取消注册，在同一目录以管理员身份执行：

```powershell
.\unregister-tsf.ps1
```

取消注册脚本只移除该输入法注册，不删除程序文件或用户词库。之后注销并重新登录，确保应用释放 DLL。**此开发会话没有替你执行系统注册/取消注册。**

## 输入操作

| 按键 | 行为 |
|---|---|
| 英文字母 | 拼音 / 日语罗马字 / 英文共享编码，显示三语候选 |
| 空格 | 确认本组词，剩余拼音继续选词，最后一组完成时提交 |
| 1–9 / Shift+1–9 | 选择当前语言上行 / 下行候选 |
| Tab / Shift+Tab | 按显示顺序切换语言 / 反向切换 |
| ↑ / ↓ | 移动候选 |
| PgUp / PgDn | 翻页 |
| Enter | 提交原始编码，按英文宽度输出 |
| Backspace | 删除一个组合字符 |
| Esc | 删除当前组合，保留此前已提交文字 |
| 标点 | 中文组使用中文标点，其他语言保留原有标点 |
| Ctrl+Alt+空格 | 在当前应用的 TSF 服务实例内切换直通 / 三语输入 |
| Ctrl+Alt+1 / 2 / 3 | 在当前应用内临时开关中 / 日 / 英候选 |

选择 Penda 配置文件后默认启用三语输入，不需要切回英语键盘。快捷语言开关是应用内临时状态；永久、跨应用的默认语言请在设置程序中保存。Windows 快捷键或应用快捷键如有冲突，以实际应用接收情况为准。

纯数字不弹候选；全角数字设置启用时，通过 TSF 直接提交全角数字。组合中的 1–9 和 Shift+1–9 用于选词，混合英文数字可先 Enter 提交英文，再输入数字。

组合文字直接存在目标应用的 TSF 文本范围中。失去焦点或注销服务时，保留未完成的原始编码并结束组合，不把文字发送到新窗口。只读、禁用输入上下文，以及应用报告的 Password / Private 输入作用域不拦截。

## 设置与独立词库

从输入法图标的右键菜单打开“设置与词库…”。设置窗口关闭即退出，没有独立托盘图标或开机启动选项。支持分别管理中文、日语、英语词库：

- UTF-8 TSV / JSON 导入、导出；中文另支持常见 `.scel` 的 0x44 / 0x45 布局。
- 导入按编码与词语合并，保留较高词频。SCEL 只导入中文，不支持加密变体、`.bin` 或 SCEL 导出。
- 中文编码使用无声调全拼；日语用罗马字，例如 `nihongo` → `日本語`；英语用词形编码。
- TSV 每行用真实 Tab 分隔：编码、词语、可选整数词频。例如 `nihao<Tab>你好<Tab>1000`。
- JSON：`[{"Key":"nihongo","Text":"日本語","Frequency":1000}]`。

数据保存在 `%LOCALAPPDATA%\Penda`：`settings.json`，以及 `dictionaries\chinese.json`、`japanese.json`、`english.json`。三种词库彼此独立。`engine.pdat` 是自动编译的原生运行索引，请通过设置程序重新生成，不要手工编辑。

保存设置或导入成功后会生成新索引。原生服务在下一次开始组合时检查更新并后台加载，当前组合继续使用旧索引；加载完成后再开始下一次输入即可使用新词库。每个目标进程共享其只读索引快照，不跨进程运行 .NET 或启动查询服务。

内置词库仍是小型演示词库，实际使用建议导入有合法使用权限的完整词库。SCEL 解析参考：[scel2txt 格式说明](https://github.com/lewangdev/scel2txt)。测试覆盖常见布局，尚未用用户真实词库验收。

## 全半角与外观

英文、数字默认半角，汉字和假名默认全角；英文、数字、假名可分别设置。半角假名采用 Unicode 半角片假名，例如 `が → ｶﾞ`；平假名先转为片假名。Unicode 没有通用半角汉字，设置中明确显示为标准汉字宽度。

原生候选窗使用深色背景、高亮行、语言色标、六项分页和 DPI 缩放；置顶但不取得输入焦点。位置通过 `ITfContextView::GetTextExt` 跟随真实 TSF 光标。应用无法提供布局或光标被裁剪时隐藏候选窗，后续布局通知再显示。

主题设置入口与独立 UI 层保留；0.2 尚无用户自定义皮肤编辑器。

## 构建、发布与安装包

需要 Visual Studio 2022 的“使用 C++ 的桌面开发”、Windows SDK，以及 .NET 9 SDK。设置程序可发布为自带运行环境的独立版；原生输入 DLL 本身无需 .NET 或单独安装 VC++ Runtime。

在项目根目录：

```powershell
# 编译 x64 和 x86 TSF DLL
.\scripts\build-tsf.ps1

# 发布完整 TSF 包，设置程序自带运行环境
.\scripts\publish.ps1 -SelfContained

# 运行托管引擎检查、原生一致性和 TSF 文本存储集成检查
.\scripts\test-tsf.ps1

# 安装 Inno Setup 6 后，生成带注册/取消注册流程的安装包
.\scripts\build-installer.ps1
```

安装包输出为 `artifacts\installer\Penda-TSF-Setup-0.2.0.exe`，默认安装到 Program Files\Penda，需要管理员权限。注册 x64 / x86 COM DLL 和 TSF 配置文件；卸载前取消对应注册。正式发行还需验证安装/升级/卸载，并签名程序和安装包。

Inno Setup 不在默认目录时使用：

```powershell
.\scripts\build-installer.ps1 -Compiler 'C:\实际位置\ISCC.exe'
```

## 开机自动启动

**TSF 输入法由 Windows 按需加载，不需要把设置程序设为开机启动。** 登录后选择或保留 Penda 输入法即可。设置窗口只从输入法菜单按需打开。

## 0.2.2：候选窗防闪烁修复

原生候选窗在 TSF 暂时报 TS_E_NOLAYOUT 时不再立即隐藏，而是保留当前帧并进行有限次数的延迟重试。窗口固定为六行高度，锚定组合起点，避免每次按键跟随组合末尾移动及随候选数缩放。仅在位置或尺寸实际变化时调整窗口，使用无背景擦除的双缓冲完整帧重绘。

x64/x86 集成回归已覆盖暂缺布局仍保持可见、连续输入几何稳定、复用窗口句柄和取消输入后隐藏。新版 DLL 已更新至 artifacts\tsf-package 原注册路径，旧 DLL 留有明确文件备份。正在运行的应用仍可能使用旧 DLL，需要注销 Windows 并重新登录使所有进程加载修复；无需重新注册或重新导入词库。实际应用中的视觉体验需重新登录后确认。
## 0.2.3：按语言分组的横向双行候选

三语分组并排，各两行、每行三列。中文第一行用 1–3，日语用 4–6，英语用 7–9；第二行用对应的 Shift+数字。关闭某种语言不会改变其他语言的数字编号。空槽显示横线，按其快捷键不提交。每页每语六项，PgUp/PgDn 同时翻页；空格提交高亮项，鼠标可点击任意候选。组合期间 Shift+1–9 优先用于第二行选词，直接输出编码可使用 Enter。

设置程序实际候选窗预览同步为同一布局，顶部显示 0.2.3。沿用 0.2.2 防闪烁逻辑，尺寸由启用语言数确定，不随每次按键的候选数变化。双架构回归覆盖所有数字/Shift数字的语言、行列及页码映射，并验证 TSF Shift+1 提交第二行而非标点。

新版 DLL 已替换原注册路径的文件并保留旧文件备份。保存工作后注销 Windows 并重新登录，使已运行的进程加载新版。无需重新注册，也无需重新导入词库。
## 0.2.4：Tab 选择当前语言组（取代 0.2.3 编号方式）

按用户选择改为每种语言横向两行、每行最多九格，各语言组上下排列。Tab 在已启用语言组之间循环，Shift+Tab 反向切换。高亮标题标出当前语言，1–9 选择其第一行，Shift+1–9 选择其第二行；不再给中文、日语、英语分别分配 1–3/4–6/7–9。空槽不提交，空格只确认当前组的高亮候选。鼠标可直接选择任意组，Enter 仍输出原始编码。

## 0.4.0：长拼音组词、中文标点和个人学习

中文检索新增有界束搜索，按词库中的完整拼音词条切分输入，组合成句子候选，并提供可先确认的前段词。选前段后，已确认文字与剩余拼音继续保留在同一 TSF 组合中；最终完成时学习完整拼音与最终文字。输入支持每段最多 512 字母，超过后先保留原文并开启下一段，避免原先 64 字母上限之后无声丢键。候选区增加当前高亮词的宽幅预览。字典未覆盖的内容保留原编码，不承诺自动生成正确汉字。

当前语言为中文时，常见标点转换为 ，。？！；：（）【】《》、“”‘’。单独输入和选词后输入都支持；组合中的 Shift+1–9 仍优先用于第二行选词，感叹号等可在上屏后输入。日语、英语组的标点保持各自原有逻辑。

## 0.6.0：分组选词与单一输入法入口
中文候选改为前缀词组，单个候选最多八个 UTF-16 单元。长拼音不再自动铺满整句：例如 nihaoxiexie，先选“你好”，剩余 xiexie 接着选择“谢谢”，最后一起提交。学习记录保留完整句子以及实际选择的各组，长句再次输入仍按短词组选择。
